SVS Experience V21
================

1) Double-click START_V21_DEVELOPMENT.bat
2) Open the URL printed in PowerShell, usually http://127.0.0.1:5173
3) Stop development server with Ctrl+C

Manual commands:
cd into the extracted SVS_Experience_V21_GitHub_Pages folder
npm ci
npm test
npm run dev

GitHub deployment:
Double-click PUSH_V21_GITHUB.bat
In GitHub Settings > Pages > Source choose GitHub Actions.
Review workflow results under Actions.
